# Flux Rec

Flux Rec is Ripo Team's private Rec Room revival — a community-run rebuild of the
game Rec Room (which shut down June 1, 2026), playable through our own launcher.

## Status

**Private development.** The repo stays private until the project is ready for a
public, application-based launch.

## Layout

- `client/` — game client mods and patches (BepInEx plugin sources, client tooling)
- `server/` — backend services (API workers, static catalogs, migrations)
- `launcher/` — the Flux Rec installer/launcher (auto-update, BepInEx bootstrap)
- `docs/` — architecture notes, runbooks, API references

## Rules

- Zero spend: free tiers only, no cards anywhere.
- No shipping without real Windows runtime proof.
- Never require Steam.
